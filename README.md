# Exercícios de Python

Este repositório contém os exercícios desenvolvidos durante a disciplina de programação, utilizando a linguagem Python.

O objetivo dos exercícios foi praticar conceitos básicos e intermediários de programação, desenvolvendo a lógica de programação e conhecendo diferentes recursos da linguagem.

## Conteúdo dos exercícios

### Conceitos básicos
- Hello World
- Soma de dois números
- Cálculo da área do círculo
- Conversão de temperatura de Celsius para Fahrenheit
- Tabuada
- Números pares
- Verificação de números pares e ímpares

### Strings
- Verificação de palíndromos
- Inversão de uma palavra
- Contagem de caracteres
- Contagem de palavras
- Contagem de letras em uma frase
- Contagem de vogais
- Verificação de anagramas
- Cifra de César
- Descriptografia da Cifra de César

### Matemática e lógica
- Fatorial
- Sequência de Fibonacci
- Números primos
- Soma dos dígitos de um número
- Conversão de metros para centímetros
- Média e desvio padrão

### Listas
- Encontrar maior e menor número
- Ordenação de listas
- Soma dos números de uma lista
- Cálculo da média de uma lista
- Classificação de números positivos, negativos e zeros
- Contagem de números repetidos
- Remoção de números repetidos

### Algoritmos
- Busca Binária
- Ordenação por Bolha (Bubble Sort)
- Ordenação por Inserção (Insertion Sort)
- Matriz Transposta

### Jogos e aplicações
- Jogo de adivinhação
- Calculadora
- Jogo da Forca
- Jogo da Velha
- Gerador de senhas
- Gráfico de barras utilizando Matplotlib

### Outros exercícios
- FizzBuzz
- Validação de quantidade de caracteres de um CPF
- Gerenciamento de uma lista de itens

## Tecnologias utilizadas

- Python
- Google Colab
- Matplotlib

## Sobre o arquivo

O arquivo `Markdown.md` contém os códigos dos exercícios desenvolvidos durante a disciplina, juntamente com exemplos de execução e resultados obtidos.

Os exercícios foram realizados de forma progressiva, começando por conceitos básicos de Python e avançando para estruturas de repetição, listas, manipulação de strings, algoritmos de busca e ordenação e pequenos jogos.

## Objetivo

O objetivo principal deste trabalho foi desenvolver e praticar a lógica de programação utilizando Python, colocando em prática diferentes estruturas e recursos da linguagem.# Disciplina-de-Intelig-ncia-Artificial
